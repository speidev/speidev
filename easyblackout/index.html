// Statement

One hotkey. Every screen, every LED, dark.

EasyBlackout is a Windows tray utility. One press blacks out every monitor and every RGB peripheral on the machine: keyboard, mouse, headset, fans, RAM, GPU and LED strips. Press it again and everything comes back exactly as it was, with each vendor's own lighting profile back in charge.

Ctrl+Alt+B

// How it stays honest

01Vendor SDKs are only engaged during a blackout. The rest of the time iCUE, Synapse, G HUB and GG run your lighting as usual.
02On restore, control is released rather than repainted, so each vendor's own profile comes back, animations included.
03Devices that no API can reach are listed as Not controllable. EasyBlackout never claims a device is dark when it isn't.
04If the app exits or crashes mid-blackout, an emergency restore runs, and every vendor app reclaims its lighting once the process is gone.

// Integrations

DisplaysEvery monitorA topmost black overlay per monitor, in physical pixels with per-monitor DPI. Optional per-monitor DDC/CI hardware power-off gives true zero light.
Corsair iCUESDK v4Exclusive lighting control, held only while blacked out. On restore the LEDs go transparent and control is released.
Razer ChromaREST SDKA Chroma session exists only during the blackout. Deleting it hands control back to Synapse.
Logitech G HUBLED SDKThe SDK is initialised only during the blackout. LogiLedShutdown returns control to G HUB.
SteelSeries GGGameSenseBlack game events while blacked out. stop_game returns control to GG.
HyperXNative HIDNGENUITY has no SDK, so black direct-mode frames are streamed instead. The firmware reverts to its onboard lighting within about 50 ms of the stream stopping.
Dynamic LightingWindows LampArrayHID LampArray devices with no vendor app, opened only while the overlay is in the foreground.
OpenRGBSDK serverMotherboard, RAM, GPU and strips. Each controller's mode and colors are saved first, then written back on restore.
